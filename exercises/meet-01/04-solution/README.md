# Solution

# Tujuan

Menjadi referensi pembanding setelah kamu mengerjakan `../03-challenge`
sendiri — bukan jalan pintas untuk menyalin sebelum mencoba.

# Yang Dipelajari

Membaca kode orang lain dan membandingkannya dengan pendekatanmu
sendiri adalah kebiasaan yang sama pentingnya dengan menulis kode
dari nol (lihat `../02-buggy`).

# File yang Harus Diedit

Tidak ada — folder ini read-only, untuk dibaca dan dibandingkan.

# Langkah

1. Selesaikan dulu `../03-challenge/easy`, `medium`, dan `hard` versimu
   sendiri.
2. Baru buka folder solusi yang sepadan di sini untuk membandingkan.
3. Kalau ada bagian solusi yang caranya beda dari punyamu tapi
   hasilnya sama — itu normal. Coding punya banyak jalan benar.

# Hint

- Jangan buka folder ini SEBELUM mencoba sendiri — kamu akan
  kehilangan latihan berpikirnya.
- Fokus membandingkan STRUKTUR dan LOGIKA (urutan kondisi, kenapa
  pakai `if` terpisah vs `elif`), bukan mencari kode yang "sama
  persis" dengan punyamu.

# Checklist

- [ ] Sudah menyelesaikan `../03-challenge/easy` sebelum membuka `easy/` di sini.
- [ ] Sudah menyelesaikan `../03-challenge/medium` sebelum membuka `medium/` di sini.
- [ ] Sudah menyelesaikan `../03-challenge/hard` sebelum membuka `hard/` di sini.

# Hasil Akhir

versi jawaban yang "benar".

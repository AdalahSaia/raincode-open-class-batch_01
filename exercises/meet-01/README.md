## Cara Menjalankan

Semua latihan adalah file `.py` tunggal — tidak butuh instalasi
library tambahan.

1. Buka folder ini di VS Code.
2. Buka file yang mau dikerjakan.
3. Jalankan lewat terminal: `python nama_file.py`
   (atau tombol ▶ Run Python File kalau pakai extension Python VS Code).

## Prinsip Belajar

- **Tebak dulu, baru jalankan.** Banyak latihan minta kamu menuliskan
  jawaban di komentar SEBELUM menjalankan kode — itu bagian dari
  latihannya, jangan dilewati.
- **Baca kode dari atas ke bawah**, tapi kalau ada function, telusuri
  dari titik pemanggilannya dulu, baru masuk ke definisinya.
- **Error bukan tanda gagal.** Baca pesannya, itu petunjuk paling
  jujur tentang di mana masalahnya.
- **`02-buggy` sebelum `03-challenge`.** Kebiasaan membaca & memperbaiki
  kode adalah bekal sebelum menulis kode sendiri dari nol.

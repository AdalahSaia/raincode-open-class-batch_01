# Ekspektasi Hasil

Setiap file, setelah dikerjakan dan dijalankan dengan
`python nama_file.py`, mencetak output yang sesuai dengan yang
dideskripsikan di komentar dalam file itu sendiri (banyak yang sudah
mencantumkan "Output yang seharusnya muncul").

# Hint

- File `01`, `02`, `04`, `05`, `08`, `09` bertema **"tebak dulu, baru
  jalankan"** — tulis jawabanmu di komentar `# tebak: ???` SEBELUM
  menjalankan. Kalau langsung dijalankan tanpa menebak, kamu
  kehilangan latihan intinya.
- File `06_if_else.py` sengaja punya `if ???:` yang belum valid Python
  — ganti `???` dengan kondisi yang benar supaya file bisa jalan.
- Nama file `01_tebak_output_01 copy.py` dan
  `03_variabel_serderhana.py` memang mengandung typo pada nama filenya
  — bukan kesalahan kamu, itu bawaan dari materi aslinya.

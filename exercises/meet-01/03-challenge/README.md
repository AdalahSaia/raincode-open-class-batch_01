# Challenge

# Tujuan

Menguji kemampuanmu menulis program dari sebuah cerita/spesifikasi,
tanpa latihan langkah-demi-langkah — cuma ada skenario dan aturan
yang harus kamu terjemahkan jadi kode.

# Yang Dipelajari

Ketiga challenge di sini HANYA memakai materi dari `../01-latihan` —
variabel, tipe data, operator, `if/elif/else`, dan `input()`. Tidak
ada konsep baru, hanya kombinasi yang lebih kompleks.

# File yang Harus Diedit

Kerjakan berurutan sesuai tingkat kesulitan:

| Level | Folder | Fokus |
|---|---|---|
| Easy | [easy](easy) | if / elif / else + perbandingan string |
| Medium | [medium](medium) | Kalkulasi bertingkat + format cetak rapi |
| Hard | [hard](hard) | Banyak input + banyak kondisi independen |

> Catatan: nomor di depan nama file (`01_`, `02_`, `03_`) adalah urutan
> pembuatan aslinya, BUKAN urutan tingkat kesulitan — tingkat
> kesulitannya ditunjukkan oleh nama folder (`easy`/`medium`/`hard`).

# Ekspektasi Hasil

Baca `README.md` di masing-masing folder level untuk spesifikasi
lengkapnya (juga tertulis di komentar `CERITA` & `SPESIFIKASI PROGRAM`
pada file `.py`-nya), lalu kerjakan bagian "TULIS KODE DI SINI".

# Hint

- Sudah mentok? Kunci jawaban ada di `../04-solution` — tapi coba dulu
  sendiri minimal 15-20 menit sebelum melihatnya.
- Kerjakan spesifikasi satu per satu dari atas ke bawah — jangan
  langsung menulis semuanya sekaligus.

# Checklist

# Hasil Akhir

Tiga program kecil yang kamu bangun sendiri dari cerita ke kode —
bukti kamu sudah bisa berpikir seperti developer, bukan cuma mengisi
titik-titik.

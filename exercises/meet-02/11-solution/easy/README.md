# Tujuan

Referensi pembanding untuk `10-challenge/easy`.

# Yang Dipelajari

Cara menyusun HTML dasar (`h1`, `h2`, `p`, `ul`/`li`, `img`) dan CSS
dasar (`color`, `background`, `padding`, `border-radius`) menjadi satu
kartu ucapan yang rapi.

# File yang Harus Diedit

Tidak ada — folder ini untuk dibaca, bukan diedit.

# Langkah

1. Struktur HTML dibungkus dalam satu `div.kartu` supaya CSS-nya
   mudah diterapkan sekaligus.
2. `body` diberi warna latar supaya kartu putihnya kontras.
3. `.kartu` diberi `background`, `padding`, `border-radius`, dan
   `text-align: center` supaya semua isinya rapi ke tengah.

# Hint

Bandingkan struktur `div.kartu` di sini dengan `.card` di
`04-css-profile` — polanya sengaja sama supaya kamu terbiasa
menggunakannya berulang.

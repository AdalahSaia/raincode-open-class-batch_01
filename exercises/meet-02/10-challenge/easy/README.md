# Challenge Easy · Kartu Ucapan

# Tujuan

Melatih kemampuan menyusun HTML dan CSS dasar dari sebuah spesifikasi,
tanpa TODO langkah-demi-langkah.

# Yang Dipelajari

Materi yang dipakai: tag `h1`/`h2`, `p`, `ul`/`li`, `img`, serta
properti CSS `color`, `background`, `font-size`, `padding`, `margin`,
`border-radius`. **Tidak ada flexbox atau JavaScript** di level ini.

# File yang Harus Diedit

- `index.html`
- `style.css`

# Langkah (Spesifikasi)

Bangun satu halaman "Kartu Ucapan Ulang Tahun" berisi:

1. Judul (`h1`) berisi ucapan, misalnya "Selamat Ulang Tahun, Sari!".
2. Satu `img` (boleh pakai `https://placehold.co/200x200` sebagai
   gambar kue/hadiah).
3. Satu paragraf (`p`) berisi ucapan/doa singkat, minimal 2 kalimat.
4. Judul kecil (`h2`) "Harapan untukmu", diikuti daftar (`ul`/`li`)
   berisi minimal 3 harapan.
5. Bungkus semuanya dalam satu `div` dengan class (misal `kartu`),
   lalu beri gaya lewat CSS supaya terlihat seperti kartu ucapan:
   - Latar belakang halaman (`body`) diberi warna.
   - Kartu diberi `background: white`, `padding`, dan `border-radius`
     supaya sudutnya membulat.
   - Judul diberi warna yang berbeda dari teks biasa.

# Hint

- Kerjakan `index.html` sampai semua tag lengkap dan tampilannya
  masuk akal (walau masih polos), baru pindah ke `style.css`.
- Kalau bingung mulai dari mana, lihat lagi struktur di
  `02-html-profile` — polanya mirip: header/judul, lalu beberapa
  bagian konten.

# Checklist

- [ ] Ada `h1` ucapan, `img`, dan paragraf doa.
- [ ] Ada `h2` + daftar harapan minimal 3 item.
- [ ] Semua dibungkus dalam satu kartu dengan `background`, `padding`,
      dan `border-radius`.
- [ ] Warna latar halaman dan warna judul sudah diatur.

# Hasil Akhir

Satu halaman kartu ucapan ulang tahun yang enak dilihat, siap
"dikirim" ke temanmu (dalam bentuk link file lokal, tentunya).

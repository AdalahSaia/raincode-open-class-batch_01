# 10 · Challenge

# Tujuan

Menguji kemampuanmu membangun halaman dari nol, tanpa TODO
langkah-demi-langkah — hanya spesifikasi. Tiga tingkat, dari yang
memakai HTML+CSS dasar, sampai yang menggabungkan HTML+CSS+JS.

# Yang Dipelajari

Semua challenge di sini HANYA memakai materi yang sudah kamu pelajari
di Bagian 1-7 — tidak ada konsep baru. Bedanya, kali ini kamu yang
menentukan strukturnya sendiri dari sebuah cerita/spesifikasi.

# File yang Harus Diedit

Kerjakan berurutan:

| Level | Folder | Materi yang dipakai |
|---|---|---|
| Easy | [easy](easy) | HTML dasar + CSS dasar |
| Medium | [medium](medium) | HTML + CSS + Flexbox |
| Hard | [hard](hard) | HTML Forms + CSS + JavaScript (DOM) |

# Ekspektasi Hasil

Baca `README.md` di masing-masing folder level untuk spesifikasi
lengkapnya, lalu bangun halamannya di `index.html` / `style.css` /
`script.js` folder tersebut.

# Hint

- Sudah mentok? Kunci jawaban ada di `11-solution` — tapi coba dulu
  sendiri minimal 15-20 menit sebelum melihatnya.
- Bangun HTML dulu sampai strukturnya benar, baru masuk ke CSS,
  baru terakhir JavaScript (kalau ada). Jangan kerjakan tiga-tiganya
  bersamaan.

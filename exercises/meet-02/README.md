# Pertemuan 2 — Membangun Website Pertamamu

HTML · CSS · JavaScript dasar. Project akhir: **Website Profil Diri**.

Minggu lalu kamu melatih logika pakai Python (variabel, if-else, function).
Minggu ini, logika itu keluar dari terminal dan menjadi sesuatu yang **terlihat di layar**.
Website hanyalah tiga lapisan yang ditumpuk:

| Lapisan | Peran | Analogi |
|---|---|---|
| HTML | Kerangka — struktur & isi | Tulang manusia |
| CSS | Tampilan — warna, jarak, tata letak | Otot & kulit |
| JavaScript | Interaksi — reaksi terhadap pengunjung | Otak |

Project profilmu tumbuh sepotong demi sepotong di setiap folder latihan, sampai
di `08-final-project` menjadi satu halaman web utuh.

## Cara Menjalankan

Semua latihan adalah file statis (`index.html` + `style.css` + `script.js`) —
tidak butuh `npm install`, server, atau konfigurasi apa pun.

1. Buka folder latihan di VS Code.
2. Klik kanan `index.html` → **Open with Live Server** (atau tombol *Go Live*
   di pojok kanan bawah).
3. Browser terbuka otomatis dan halaman ikut ter-refresh tiap kamu menyimpan.

Kalau belum punya extension-nya: buka tab Extensions (`Ctrl+Shift+X`), cari
**Live Server** oleh Ritwick Dey, lalu install.

## Prinsip Belajar

- **Baca dulu, baru menulis.** Tiap file punya komentar yang membimbing —
  jangan lompat ke jawaban.
- **Polos itu normal.** Sebelum ada CSS, tampilan memang hitam-putih dan
  menumpuk ke bawah. Itu bukan tanda ada yang salah.
- **Error itu petunjuk, bukan bencana.** Buka DevTools (`F12` atau klik kanan
  → Inspect) tiap kali sesuatu tidak sesuai harapan. Baca pesannya dari bawah.
- **`09-buggy` sebelum `10-challenge`.** Kebiasaan membaca & memperbaiki kode
  orang lain adalah bekal utama sebelum menulis kode sendiri dari nol.

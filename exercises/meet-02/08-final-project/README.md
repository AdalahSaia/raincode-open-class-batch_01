# 08 · Final Project

# Tujuan

Menggabungkan semua yang sudah dipelajari di Bagian 1-7 menjadi satu
**Personal Profile Website** yang utuh: berstruktur rapi (HTML),
enak dilihat (CSS), dan benar-benar interaktif (JavaScript).

# Yang Dipelajari

- Merangkai HTML, CSS, dan JavaScript jadi satu halaman yang saling
  terhubung — bukan lagi latihan terpisah.
- Menerapkan ulang pola card (`04-css-profile`), flexbox
  (`05-flexbox`), dan interaksi DOM (`07-dom-interaction`) dalam satu
  konteks project nyata.
- Mempersonalisasi tampilan (warna, konten) menjadi milikmu sendiri.

# File yang Harus Diedit

- `index.html` — `TODO 1` sampai `TODO 3` (personalisasi konten).
- `style.css` — `TODO 4` sampai `TODO 6` (warna tombol).
- `script.js` — `TODO 1` dan `TODO 2` (function `sapa()` dan `kirimPesan()`).

# Ekspektasi Hasil

Satu kartu profil di tengah halaman berisi:
1. Foto, nama, peran, dan deskripsi singkat (versimu sendiri).
2. Chip hobi yang berjejer rapi lewat flexbox.
3. Tautan sosial media yang berjejer rapi.
4. Form pesan: ketik sesuatu di kotak, klik "Kirim" &rarr; muncul
   ucapan terima kasih dan kotak input kembali kosong.
5. Tombol "Sapa Saya" &rarr; muncul kalimat sapaan.

# Hint

- Kerjakan HTML dan CSS dulu (personalisasi konten & warna), baru
  masuk ke JavaScript — supaya kamu bisa lihat hasil visualnya
  sebelum menambah interaksi.
- Kalau tombol tidak bereaksi, cek Console (F12) dulu sebelum menebak-
  nebak. Error biasanya langsung menunjuk baris yang salah.
- `.value = ""` adalah cara mengosongkan kembali sebuah input lewat JS
  — berguna supaya form terasa "beres" setelah dikirim.

# Checklist

- [ ] Konten profil (deskripsi, hobi, sosial media) sudah dipersonalisasi.
- [ ] Tombol "Sapa Saya" memunculkan kalimat sapaan.
- [ ] Tombol "Kirim" memunculkan ucapan terima kasih dan mengosongkan input.
- [ ] Warna tombol sudah dipersonalisasi (tidak polos abu-abu).
- [ ] Semua tag HTML tertutup rapi & tidak ada error di Console.
